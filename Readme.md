## Descrição do Projeto

Este repositório contém a implementação de um agente inteligente baseado em **Inferência por Lógica Proposicional** e **Busca em Largura (BFS)** para resolver o clássico problema do Mundo de Wumpus. O projeto expande o problema tradicional ao permitir a geração de cenários customizados com múltiplos monstros (Wumpus) e múltiplos buracos distribuídos em tabuleiros de diferentes dimensões.
